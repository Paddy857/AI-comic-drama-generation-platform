## 1. 产品概述

### 1.1 产品定位
面向 **短剧团队批量产能场景** 的 **模板化漫剧生产工具**。核心价值：**100套爆款结构的漫剧模板预置好，短剧团队只需要把自己的角色/对白/细节「填空式替换」，30分钟量产一条合格成片，新人也能稳定产出团队标准水平的内容。**

### 1.2 目标用户画像
- **短剧MCN/团队的量产小组**：一天要出5-10条漫剧账号内容，质量底线稳定 > 单条个性化创意
- **短剧团队的新人运营**：独立编剧能力不足，需要「照着葫芦画瓢」先做合格产出
- **题材试投小组**：同一个故事框架换5套人物设定投抖+测试数据，挑跑量款放量
- **核心诉求**：**快、稳、可批量复制、新人上手0门槛**

### 1.3 核心设计原则
1. **模板即最佳实践**：每个模板都是经过平台和合作团队验证的「爆款结构」，镜头数量、节奏、情绪曲线、反转点都预置到最优
2. **填空式输入**：用户不需要「创作」，只需要「替换变量」——角色名、人物特征、关键对白、细节描述。模板结构、镜头数、景别运镜全部锁死，不允许新手乱改导致质量崩坏
3. **批量一次出N条**：填一次变量表 → 选择多套风格/角色组合 → 一次生成3-5条变体，用于AB测试
4. **渐进开放高级编辑**：默认填空模式；如果用户确实想改结构，可「解锁高级模式」（弹二次确认提示：「解锁后模板结构保护将关闭，成片质量无法保证，确定继续？」）

## 6. 数据埋点与效果衡量

### 6.1 核心漏斗
```
进入平台
  → 模板中心选模板（≥75%）
  → 完成必填变量填写（≥90%，因为只有2-3个）
  → 点击开始生成（≥85%）
  → 成功出第一条片（≥95%）
  → 完成新人3条任务（≥40%）
  → 7日内回来出第二批（≥35%）
```

### 6.2 量产效率关键指标
- **单条平均耗时**（从选模板到出片）：中位数 ≤ 35分钟（含填写时间，对比自由模式120分钟+）
- **新人首次出片平均耗时**：≤ 15分钟（3必填走默认值即可）
- **每用户日均出片数**（活跃用户）：≥ 2.5条 / 天
- **高级模式转化率**（填空→解锁高级）：≤ 10%（>10%说明模板不够用/填空模式满足不了需求，需要加模板而不是让用户去高级）
- **变体复用率**：每条成片之后生成变体的比例 ≥ 50%（说明魔改变体功能在被使用，用户觉得有用）
